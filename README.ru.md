# Local AI Project Board — локальная доска AI-проектов

Проекты, спринт, поручения, результаты, история и архив. Автоматический запуск
поддерживается для **Codex и Hermes**; для других оболочек — копирование поручения.
Личные проекты и переписки автора в репозиторий не входят.

## Установка и запуск

Нужны Git и Python 3.11+. Дополнительные Python-пакеты не нужны.

```sh
git clone https://github.com/vichepaev22/local-ai-project-board.git
cd local-ai-project-board
python run.py --open
```

На macOS/Linux команда может называться `python3`. Откройте
<http://127.0.0.1:5137/>. Можно запускать из терминала Codex, Hermes или другой
оболочки. Сам запуск доски не отправляет поручения модели.
Windows: `Start-Dashboard.cmd`; macOS/Linux: `sh start.sh --open`.
Остановка — Ctrl+C в терминале. Фоновый запуск: `python run.py --background --open`;
он выводит PID. Штатная остановка: `python run.py --stop` (добавьте `--port`, если
меняли порт). Не завершайте сервер принудительно во время работы исполнителя:
отдельные процессы могут остаться; перед повтором проверьте их самостоятельно.
Если порт занят, выберите другой: `--port 5140`. Не останавливайте чужой процесс.

## Три режима

По умолчанию — **ручной**. Создайте карточку и поручение, нажмите
«Скопировать поручение» и вставьте его в выбранную AI-оболочку.
Результат другого приложения автоматически обратно не импортируется.

Для автоматического запуска установите, авторизуйте и настройте соответствующую
оболочку отдельно, затем запустите доску в одном из режимов:

```sh
python run.py --bridge codex --open
python run.py --bridge hermes --open
```

Не запускайте две команды на одном порту одновременно. Смена режима — остановить
свою доску и перезапустить её. В карточке укажите **абсолютный путь к существующей
папке проекта**. Добавьте поручение, откройте «Поехали», проверьте пакет и подтвердите.
До подтверждения — только сохранение. После запуска проверяйте итог, а не процент
этапа процесса. Архив сохраняет результаты и историю; перезапуск не повторяет задания.

## Права и ограничения

Codex подключается через локальный app-server и использует одобрения Codex.
Hermes работает через CLI с вашим провайдером, инструментами и правами. Это **не
песочница Codex**; запросы могут стоить денег. Доска не добавляет `--yolo`, `-z`
или автоматическое принятие hooks и не меняет настройки безопасности Hermes.
Ваша конфигурация может уже разрешать опасные команды — проверьте её самостоятельно.
[Правила безопасности Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/security/).

Протокол Hermes проверен по локальной v0.21.3 (`c62bd9f2`) и
[официальной справке CLI](https://hermes-agent.nousresearch.com/docs/reference/cli-commands/).
Другие версии/провайдеры требуют отдельной проверки. Ошибки провайдера, пустой ответ,
отсутствующий CLI и тайм-аут не выдаются за успешное выполнение.
Для других оболочек автоматического адаптера в первой версии нет.

## Данные

Пустая доска создаётся в `data/`, журналы — в `logs/`; они исключены из Git.
Данные содержат пути, поручения, ответы и идентификаторы сессий — храните их приватно.
Для резервной копии остановите сервер и скопируйте всю папку `data/`.
Путь можно изменить: `--data-dir <папка> --log-dir <папка-журналов>`.
Существующие файлы при старте не перезаписываются. Черновики и предпочтения
браузера остаются на устройстве. Ключи провайдеров задаются в самой оболочке,
не в доске, поручениях или GitHub.

Сервер слушает только `127.0.0.1`. Это локальный однопользовательский инструмент,
без авторизации: не публикуйте его через туннель и не превращайте в общий сервер.
Проверки Host/Origin не заменяют изоляцию ОС; локальные приложения могут обратиться
к доске. Доска сама не отправляет телеметрию; подключённая оболочка работает по
своим сетевым правилам.

## Дополнительные настройки и проверки

Переменные `PROJECT_BOARD_HERMES_BIN`, `PROJECT_BOARD_HERMES_MODEL`,
`PROJECT_BOARD_HERMES_PROVIDER` задают путь/модель/провайдера Hermes.
`PROJECT_BOARD_HERMES_TIMEOUT` — 300 секунд по умолчанию,
`PROJECT_BOARD_HERMES_MAX_TURNS` — 20 итераций инструментов.
Для Codex доступен `PORTFOLIO_CODEX_BIN` (абсолютный путь к исполняемому файлу).
Полная таблица и ограничения — в [English README](README.md).

```sh
python -m unittest discover -s tests -p "test_*.py"
node --test tests/*.test.cjs
```

Node нужен только для тестов. Проверки используют вымышленные данные и подменённые
транспорты, без вызовов платных моделей. CI проверяет Windows, Linux и macOS;
это не доказательство работоспособности всех провайдеров и версий оболочек.
Лицензия MIT разрешает использование и изменение проекта.
